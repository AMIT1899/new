Our Story

NORTHROW is a fictional front-end demo brand created for this static GitHub Pages store. The design language is built around restrained, versatile men’s wardrobe staples.

Designed for the everyday

We focus on clean silhouettes, practical fabrics and versatile colour palettes across casualwear, activewear and sportswear.

This static-store build

This version intentionally uses no database or backend. Product browsing, cart, wishlist and COD orders are handled locally in the browser so the full flow works on GitHub Pages.
